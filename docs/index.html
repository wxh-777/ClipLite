功能

它做的事，比你想的多一点。

Windows 自带的剪贴板只记住最后一条内容。ClipLite 捕获并恢复多种剪贴板格式，提供完整的搜索、筛选、预览与加密能力，同时保持自身的轻量。

多格式捕获与历史

自动归档所有复制内容，支持纯文本、HTML、文件列表、DIB 和 DIBV5 图片。

  • 收藏与置顶相互独立，可同时标记
  • 历史列表支持紧凑、标准和自适应三种高度
  • 路径失效的文件记录会在列表标记并确认
Alt + V（可选 Win + V）

预览、编辑与缩放

粘贴前先看清楚。图片支持悬停预览、滚轮缩放、拖拽和按需加载原图；长文本支持滚动查看。

  • 自动预览 / F2 按键预览 / 关闭预览三种模式
  • 可编辑文本或 HTML 记录为纯文本，支持替换或另存
  • 支持纯文本粘贴和富文本粘贴两种方式

搜索与组合筛选

直接在历史面板里输入关键词即可搜索。支持按类型、时间范围、内容长度、来源应用和排序方式组合筛选。

  • 搜索不区分英文大小写，支持中文
  • 可开启“打开历史窗口后直接搜索”选项
  • Ctrl+0 一键清除全部筛选条件

主题与外观

提供浅色、深色、护眼绿、护眼夜间、纸张暖色和午夜蓝六种主题，也支持创建自定义主题。

  • 可跟随 Windows 亮色/暗色模式自动切换
  • 支持蓝色、紫色、绿色和橙色强调色
  • 系统高对比度模式有对应配色

加密、隐私与安全

可选的 Windows DPAPI 用户级加密，保护密码、令牌一类的敏感剪贴内容。

  • 敏感文本支持自动过期（识别 password/token/api_key 等）
  • 可按来源应用忽略内容
  • 置顶记录可开启自动清理保护

存储管理与便携模式

支持最大记录数、磁盘空间、保留天数、单条内容大小和暂停监听等设置。普通安装与便携模式均可使用。

  • 便携版数据保存在程序目录 data\ 文件夹
  • 支持手动清理未收藏内容与按范围清理
  • 不在内存中保存完整历史正文，图片按需读取

快捷键

用键盘完成一切。

所有操作都能不离开键盘完成。下面是最常用的几个键位组合。

打开剪贴板历史 Alt+V
粘贴当前记录 Enter/单击
粘贴为纯文本 Ctrl+Shift+V
删除当前记录 Delete
关闭历史窗口 Esc
打开设置 F10
清除历史筛选 Ctrl+0
聚焦搜索框 Ctrl+F
编辑选中的文本记录 Ctrl+E
按住查看当前记录预览 F2
技术

基于原生 API，没有额外运行时。

ClipLite 不打包浏览器内核，也不引入第三方运行时。所有系统交互都直接调用 Windows 提供的接口。
